# fragrantica-want2test
Bookmarklets to move Perfumes from the "I Want" shelf to the "for test" shelf in your Wardrobe

## Usage
See https://orbanbalage.com/fragrantica-want2test/

## How to build from Source
In case the Bookmarklets stop working, the two `.js` source files should be adjusted, and then to build the minified bookmarklet code, run:
```shell
npm install
npx bookmarklet 01_main.js Open.js
npx bookmarklet 02_page.js Move.js
```
